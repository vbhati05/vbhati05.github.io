# Vanshika Bhatia Engineering Portfolio

## Preview locally
Double-click `index.html`.

## Replace images
Put your approved images in `assets/images/` and either use the existing filenames or update the `<img src="...">` paths in `index.html`.

## Add your resume
Put your resume PDF in this folder and name it `resume.pdf`.

## Update contact links
Open `index.html` in a plain-text editor and replace `YOUR_EMAIL` and `YOUR_LINKEDIN_URL`.

## Publish with GitHub Pages
1. Create a public GitHub repository.
2. Upload the CONTENTS of this folder so `index.html` is at the repository root.
3. Go to Settings > Pages.
4. Choose Deploy from a branch, then `main` and `/root`.
5. Save and wait for the published URL.

The `projects/` folder contains the detail pages linked from the homepage.
