Six-Wheeled Rover

A mobile robotics project combining custom PCB design, motor control, Arduino programming, and wireless communication.

Jul 2024 – Aug 2024

Tools & methods

Eagle · Arduino · PCB Design · Motor Drivers · HC-05 · Wireless Communication

Focus

Electronics · Controls · Hardware Integration

Overview

The six-wheeled rover project focused on integrating custom electronics, motor control, embedded software, and wireless communication into a compact mobile robotics platform.

My work covered control architecture, PCB design and assembly, Arduino programming, motor-driver integration, wireless communication, and full-system testing.

The Problem

A six-wheeled rover requires multiple motors and drivers to respond consistently through one control system while also receiving commands wirelessly.

The challenge was to consolidate the electronics and create a reliable command path from the operator to the rover's six-wheel drivetrain.

Motor Control Coordinate multiple motor drivers through a single embedded controller.
Electrical Integration Reduce loose wiring by consolidating control connections onto a custom PCB.
Wireless Operation Receive remote commands without requiring a physical connection to the rover.
System Response Translate wireless commands into predictable wheel motion and rover movement.

Control Architecture

I first defined how commands would move through the rover from the operator interface to the drivetrain.

The architecture connected: wireless input → Arduino control → motor drivers → six-wheel actuation .

Custom PCB Design

I designed a custom PCB in Eagle to consolidate connections between the Arduino controller, motor drivers, power connections, and supporting electronics.

Moving the control connections onto one board reduced the dependence on point-to-point wiring and created a cleaner hardware architecture for the rover.

Component Integration Organized motor-driver, controller, power, and communication connections on one board.
Routing Developed PCB traces to connect the control and motor-driver circuitry.
Packaging Arranged the board around the available rover electronics space.

PCB Manufacturing & Assembly

After completing the board design, I manufactured and assembled the PCB and integrated the components required for rover motion and control.

This moved the project from schematic and layout work into a physical control system that could be connected directly to the rover hardware.

Embedded Control

I programmed the rover using Arduino, developing control logic that translated incoming user commands into motor outputs.

The software provided the logic required to determine how the wheel motors responded to commands for rover movement.

Receive Command Read the incoming user instruction from the communication module.
Interpret Command Convert the input into the corresponding rover movement.
Drive Motors Send control outputs to the motor drivers.
Move Rover Coordinate wheel actuation to produce the requested vehicle motion.

Wireless Communication

I integrated an HC-05 Bluetooth module to provide wireless command transmission between the operator and rover.

This completed the control chain by allowing user commands to reach the Arduino wirelessly before being converted into motor actions.

System Testing

Once the PCB, software, motor drivers, and wireless system were integrated, I tested the complete rover as one electromechanical system.

Communication Check Verified that wireless commands were received consistently by the controller.
Command Validation Confirmed that received commands were interpreted correctly by the Arduino logic.
Motor Response Checked that the motor drivers produced the intended wheel response.
Vehicle Test Verified the complete command-to-motion sequence on the six-wheel platform.

Engineering Workflow

Design custom PCB architecture
Build PCB and electronics assembly
Program Arduino motor control
Integrate wireless six-wheel control

Outcome

The project consolidated motor control, custom PCB hardware, Arduino software, and Bluetooth communication into one rover control architecture.

The final control path connected: wireless command → embedded logic → motor drivers → six-wheel motion , enabling remote control through an integrated hardware and software system.
